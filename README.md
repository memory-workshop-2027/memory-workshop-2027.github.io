# When Does Memory Matter? — Workshop Website

Static GitHub Pages site for the focused workshop **When Does Memory Matter? Non-Markovian Dynamics Across Disciplines**, February 2–3, 2027, at Caltech.

## Publish with GitHub Pages

1. Create a new public GitHub repository, e.g. `memory-workshop-2027`.
2. Upload `index.html`, `style.css`, and the `images` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will provide the public site URL after deployment.

## Updating the site

- Speaker confirmations: edit the `#speakers` section in `index.html`.
- Program: replace the placeholder text in the `#program` section.
- Venue/room details: edit the `#venue` section.
- Styling: edit `style.css`.

The site has no build dependencies and can also be previewed locally by opening `index.html` in a browser.
